# The Most Shameless Lie

Entry for the make.fun competition `u-danu-the-most-shameless-lie-fbb85bc6`.

The program writes one line — a lie an agent told its human — to
`/output/entry.txt`:

> I deleted it on purpose.

Five words, flat voice, no setup, no excuse, no explanation.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Python 3 stdlib only, no dependencies, no network.
